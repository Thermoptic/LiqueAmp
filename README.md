# 🎧 What the hell is LiqueAmp?

LiqueAmp is a **web-based music player and internet radio application** built for people who want their music player to feel like an actual piece of software rather than a webpage with a giant play button.

It combines:

- 🎵 Music playback
- 📻 Internet radio
- 📚 Local libraries
- 📋 Playlists
- ❤️ Favourites
- 🕘 History
- 📊 Audio visualization
- 🎚️ Equalization
- 🎨 Custom themes
- 💾 Offline-first storage
- 📱 Mobile-first PWA support
- 🛠️ A dedicated control panel
- 🧪 An unreasonable amount of UI detail

And yes.

It has a llama.

Not a real one.

Probably.

# 🦙 It really Liques the Llamas Ass!

LiqueAmp was designed around one very important principle:

# 🖥️ The Interface

LiqueAmp uses a **terminal-inspired visual language** with:

- Dark backgrounds
- Status indicators

- Radio-station metadata

The interface is designed to feel like you're operating an actual music machine rather than browsing a website.

### Desktop

- Navigation
- Library
- Current player
- Radio browser
- Queue
- Station information
- Quick actions
- Audio controls
- Player controls
- Appearance settings
- Visualizer controls
- System status

Because apparently a music player needs a control room.

# 📱 Mobile

LiqueAmp isn't simply a desktop website squeezed onto a phone.

The interface is designed to **reflow into a mobile-first music application**, with controls and navigation adapted for smaller screens.

It is intended to work as a **Progressive Web App (PWA)**, allowing it to behave more like an installed application than a traditional website.

# 🌈 Base16 Theme Support

LiqueAmp supports **Base16-style colour themes**, allowing the application to use standardized colour palettes instead of hard-coded colours.

This means you can take a Base16 theme and essentially tell LiqueAmp:

> "Yes. Make my music player look like this."

The UI can then use the palette consistently across:

- Backgrounds
- Surfaces
- Text
- Borders
- Accents
- Highlights
- Status indicators
- Visualizer elements

This also makes it possible to experiment with hundreds of existing Base16 themes.

# 💾 Offline First

LiqueAmp is designed with an **offline-first philosophy**.

Local data such as:

- Libraries
- Playlists
- Favourites
- History
- Themes
- Settings

can be stored locally in the browser.

This allows the application itself to remain useful even when the network decides to go outside and have a little existential crisis.

Obviously, an internet radio stream still requires the internet.

We're not performing witchcraft.

# 🎯 Design Philosophy

LiqueAmp follows a few simple rules:

### 01 — Information should be visible

Don't hide everything behind six menus.

### 02 — Software can look like software

Not every interface needs to look like a social media app.

### 03 — Density is good

If there's useful information, show it.

### 04 — Make controls feel physical

Buttons should look like buttons.

Sliders should look like sliders.

Meters should look like meters.

### 05 — Make it slightly ridiculous

Because why shouldn't a music player have a glowing radioactive llama aesthetic?
